# Easier city contributions and downloaded scenery

Make the main Add to city action a short, mobile-friendly form. A public link suggests a name and neighborhood; the contributor can edit both, choose a downloaded building style, and let the city select an available lot. Show the building before handing a complete request to GitHub. Save an unfinished draft on this device and detect links already in the catalog.

Keep GitHub authentication and owner approval. A prepared request is not a published lot. Retain legacy five-field issue forms, support an optional allowlisted style, and never execute submitted code.

Use verified CC0 city models and props, photographed PBR road textures, and HDR lighting with source records. Preserve original Project 0 exteriors, all lot identities, desktop and multi-touch flight, the center landmark, and WebGL fallback.

Verify helper and approval behavior with Node tests, run the production build, inspect desktop and touch-browser flows including the actual GitHub handoff, then publish through the existing Pages workflow and check the live result.
